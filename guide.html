ひとり防犯ボイスの使い方

スマホで鳴らす準備から、インターホン越しの聞こえ方の確認まで。

最終更新: 2026-10-14

音声ツールを開く

1. まずスマホだけで試す

  1. 音声ツールのトップページを開きます。初回の音声読み込みには通信が必要です。
  2. 「置き配をお願いしたい」などのシーンを選ぶか、セリフと声タイプを自分で選びます。
  3. 「選んだ内容で再生」を押します。停止ボタンで途中停止できます。
  4. 室内で音が聞こえることを確認し、端末の音量ボタンで調整します。

まず控えめな音量から試してください。イヤホンやBluetooth機器へ音が出ている場合は、スマホ本体のスピーカーへ出力を戻します。再生はボタンを押したときに始まり、インターホンの呼び出しと自動連動はしません。

2. インターホンの外側に届くか確認する

スマホとインターホンの間に専用接続はありません。室内側のインターホンのマイクにスマホのスピーカーを近づけて、音を拾ってもらう使い方です。

  1. 配達の予定がない時間に、信頼できる人へ外側で聞こえ方を確認してもらいます。
  2. インターホンの通話をつなぎます。機種の操作方法は説明書で確認してください。
  3. 短いフレーズを再生し、外側で言葉が聞き取れるか確認します。
  4. 聞き取りにくければスマホの向き・距離・音量を変え、もう一度試します。

端末・インターホン・周囲の騒音によって結果は変わります。外側で試せていない場合は、届くことを確認済みとは扱わないでください。

3. フレーズと声を決めておく

在宅時の短い返答の例
場面セリフ先に確認すること
ひとまず返答するはい／はーい訪問予定と相手の用件
置き配をお願いする玄関の前に置いといてくださいその荷物が置き配に対応しているか、置き場所に支障がないか
準備の時間がほしい少々お待ちください相手が待てるか、追加の説明が必要か
お礼を伝えるありがとうございます受け渡しや依頼が完了したか

声は「若めの声（丁寧）」と「若めの声（少し素っ気ない）」を選べます。「おまかせ」はページを開いたときに1つ選び、そのページを開いている間は同じ声です。次回も同じ声になることがあります。

前回の選択はブラウザ内に保存されます。配達前にページを開き、選択中のセリフと声を見て確認してください。録音音声の使用に気づかれないことや、防犯効果を保証する機能ではありません。

4. よく使う場合はホーム画面へ

iPhoneのSafari

  1. 音声ツールのトップページをSafariで開きます。このガイドではなく、再生できるページを追加してください。
  2. 共有メニューを開き、「ホーム画面に追加」を選びます。
  3. 追加したアイコンから開き、音声再生を確認します。

AndroidのChrome

  1. 音声ツールのトップページをChromeで開きます。
  2. ブラウザのメニューから「ホーム画面に追加」または表示されるインストール項目を選びます。
  3. 追加したアイコンから開き、音声再生を確認します。

表示名や場所は端末・ブラウザの版で異なります。SNS内のブラウザで項目が見つからないときは、SafariまたはChromeで開き直してください。ホーム画面に追加するだけで音量やオフライン利用が保証されるわけではありません。

再生できないときの切り分け

症状から確認する順番
症状確認すること
操作しても音が出ない音量・ミュート設定を確認し、イヤホンやBluetoothへの出力を確認。通信を確保して再読み込みし、再生ボタンを押す。
スマホでは鳴るが相手に届かないインターホンの通話状態、室内マイクの位置、スピーカーの向きと距離を確認。
ホーム画面から開くと使い方記事が出る追加したURLを確認。再生できるトップページを開き直してから追加する。
通信を切ると再生できない音声が保存されていない可能性がある。通信を戻して試す。Web版のキャッシュは消える場合があるので、配達前に通信を切った状態で確認。

うまくいかないときは、繰り返し鳴らす前に停止し、端末とブラウザ、症状を整理してください。不具合の連絡先へ個人を特定する住所などを記載せずお知らせください。

道具の選び方と利用の限界

短い返答だけを今すぐ試したい場合はWeb版から始められます。スマホなしの物理ボタンを希望する場合は応答くんの仕様比較、外出時の通知なども必要な場合はコエマモの公式機能比較を確認できます。

このツールには身元確認・犯罪検知・緊急通知はありません。知らない訪問者に不安を感じる場合は、音声で応答することより、ドアを開けずに相手を確認することを優先してください。

警視庁の訪問者への注意喚起も参考になります。
