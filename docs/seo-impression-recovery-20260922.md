# VoiceGuard Web 検索表示回復プラン

更新日: 2026-09-22

## 結論

直近の表示回数減少は需要減だけではなく、トップページの「アプリ」検索意図との関連性を弱めた変更と時系列が一致する。

2026-09-08 の「iPhoneアプリへの導線を改善」変更では、App Store CTAを改善した一方で、トップページのH1、主要見出し、本文、構造化データから `Webアプリ・サイト` を `サイト` に置き換えた。Search Consoleでは、その変更が検索へ反映されたと考えられる期間に、アプリ系クエリとトップページの表示が大きく減っている。

CTA改善は維持し、無料Webアプリとしての説明を復元する。今後はCIのSEO契約チェックで、主力検索意図の誤削除を防止する。

## Search Console実績

対象期間はデータ提供済みの最新7日と前7日の比較。検索データは2026-09-19まで。

| 指標 | 直近7日 | 前7日 | 変化 |
|---|---:|---:|---:|
| クリック | 59 | 223 | -73.5% |
| 表示回数 | 802 | 1,918 | -58.2% |
| CTR | 7.4% | 11.6% | -4.2ポイント |
| 平均掲載順位 | 7.7 | 6.0 | 1.7位低下 |

ページ別ではトップページがクリック `221 -> 59`、表示 `1,901 -> 775`。サイト全体の減少のほぼ全てを占める。

URL検査ではトップページはGoogleに登録済みで、HTTPSも正常。主因はインデックス消失ではなく、トップページのクエリ関連性と順位の低下と判断する。

## 実施内容

1. H1を `インターホン 男性の声 アプリ・サイト（無料）` に復元。
2. ファーストビュー、主要見出し、サービス説明、SoftwareApplication / WebSite構造化データに `Webアプリ・サイト` を復元。
3. `アプリ不要` と `iPhoneアプリあり` を併記し、Web版とネイティブ版の関係を明確化。
4. FAQ構造化データの重複質問を削除。
5. sitemapのトップページ最終更新日を2026-09-22へ更新。
6. `scripts/check-seo-contract.mjs` とGitHub Actionsを追加し、主力語、H1、canonical、noindex、構造化データ、FAQ重複を継続検査。

App Store CTA、再生後CTA、GA4イベント計測は維持する。

## 公開後の判定

### 7日後

- トップページ表示回数: `775 -> 1,100以上` を回復目安にする。
- `インターホン 男性の声 アプリ 無料`: 週50表示以上へ戻るか。
- `男性応答アプリ`: 週150表示以上へ戻るか。
- 平均掲載順位: 7.7から6台へ戻るか。
- CTR: 10%以上へ戻るか。

### 14日後

- 表示が回復して順位だけ弱い: SERPと本文冒頭の不足情報を確認する。
- 順位が戻ってCTRが弱い: descriptionだけを1要素変更する。
- どちらも戻らない: URL検査、手動対策、クロール、canonical、Core Web Vitalsを再点検する。

## ガードレール

- 主力クエリ向けの類似ページを増やさない。
- title、H1、主要説明を同時に大きく変えない。
- CTA改善時も主力語を削除しない。
- 週次でトップページと主要5クエリを記録し、変更日を残す。
