# VoiceGuard Growth Strategy

Updated: 2026-06-21

## Positioning

VoiceGuard should stay a free, immediate-use safety utility. The core search intent is not "I want to shop"; it is "I need a male voice for the intercom now." Monetization should happen after the user gets value, not before.

## Strategic Thesis

1. Keep the homepage as the high-intent SEO landing page for "インターホン 男性の声 アプリ 無料".
2. Convert satisfied Web users into iOS app installs once the App Store version is live.
3. Use affiliate only for users whose anxiety remains after using the free tool.
4. Avoid intrusive ads during launch. Trust, reviews, and retention are more valuable than small ad revenue at the current traffic level.

## SEO Moat

- Homepage is the primary URL for the winning query cluster:
  - インターホン 男性の声 アプリ 無料
  - インターホン 男性の声 サイト
  - インターホン 男の声 アプリ
  - インターホン対応音声
- Do not create another exact-match landing page for the same query unless it canonicalizes back to the homepage.
- Android, iPhone, and generic voice-app pages should support the homepage with clear internal links, not compete with it.
- FAQ and HowTo structured data should reflect real user questions and real use steps, not keyword stuffing.

## Funnel

1. Search: "インターホン 男性の声 アプリ 無料" and related long-tail queries.
2. Free utility: top page voice playback.
3. Confidence step: home-screen add or iPhone app guide.
4. Remaining anxiety: safety-plan.
5. Purchase intent: recommend-intercom / recommend-buzzer.
6. Affiliate click: Rakuten links.

## App Launch Strategy

- Launch iOS app as free, ad-free, no-login, no-data-collection.
- Use Web traffic to seed first installs and early reviews.
- Emphasize native-only benefits:
  - offline bundled audio
  - playback designed for urgent use
  - delayed playback to position the phone near the intercom
- After launch, replace "公開準備中" messages with App Store CTAs.

## Monetization Strategy

- Short term: affiliate from comparison pages only.
- Medium term: App Store installs and reviews.
- Later: optional paid layer only if it improves emergency reliability.

Paid feature candidates:
- extra phrase packs
- home-screen widget / lock-screen widget
- Siri Shortcut support
- additional voice variations
- customizable delayed playback

Avoid gating:
- basic playback
- 置き配 phrase
- core safety flow

## KPIs

- Organic clicks to top page
- Launch app / playback events
- Home-screen/app-guide clicks
- safety-plan landing rate from top page
- recommend-intercom and recommend-buzzer landing rate
- aff_click rate by page and slot
- App Store product page views and downloads after launch
- App Store rating count and average rating
